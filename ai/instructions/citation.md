# Citation Rules

## 文内引用

使用仓库相对路径和行号：

```text
[ProfessionalUnity3D/第二章技术要点.md:31-39]
```

## 代码引用

```text
[GameProgrammingPatterns/Assets/OptimizationPatterns/ObjectPool/Script/Core/PoolManager.cs:80-116]
```

## 引用要求

- 每个关键结论至少有一个仓库内引用。
- 引用必须指向原始文件，不能只引用索引文件。
- 摘要可以作为线索，但不能代替原文。
- 外部资料必须单独标明来源。
- AI 推断必须使用“推断”“可能”“需验证”等明确措辞。

## 无法验证时

如果无法读取原文或无法运行测试，回答必须包含：

```text
当前未完成运行验证。
```

不得使用“已确认”“已验证”“必然”等措辞。
