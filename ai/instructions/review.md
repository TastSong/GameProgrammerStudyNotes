# Review Rules

## 状态定义

| 状态 | 含义 | Agent 使用方式 |
| --- | --- | --- |
| `draft` | 草稿 | 只能作为线索 |
| `outline` | 章节提纲 | 只能用于导航 |
| `summary` | 专题摘要 | 可作为摘要引用，需提示 |
| `reviewed` | 人工复核 | 可作为主要依据 |
| `verified` | 有测试或实验验证 | 可引用验证结论 |
| `stale` | 已过期 | 必须提示并优先查找新版 |

## 复核重点

- 技术结论是否有版本范围。
- 代码示例是否与实际文件一致。
- 性能和 GC 结论是否有测试条件。
- 网络、渲染、Unity 生命周期结论是否受版本影响。
- 外部链接是否仍可访问。
- 引用是否指向正确行号。

## 复核后

更新元数据：

```yaml
status: reviewed
reviewed_at: 2026-11-24
```

然后重新生成索引。
