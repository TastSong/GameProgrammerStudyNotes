# Game Programming Patterns 游戏编程模式

本目录包含《游戏编程模式》相关中文笔记和一个 Unity 教学示例工程。示例用于观察各模式的最小结构，并非生产级实现。

## 工程信息

- Unity 版本：`2019.4.35f1c1`
- 示例源码：28 个 C# 文件，约 2,200 行
- 示例场景：18 个
- 模式文档：19 篇

## 使用方式

1. 使用 Unity Hub 将 `GameProgrammingPatterns` 目录添加为项目。
2. 在 `Assets` 下选择对应模式的场景并进入 Play Mode。
3. 工程未配置默认 Build Settings 场景，构建前需要手动添加目标场景。

## 示例状态

- 可交互示例：命令、对象池、事件队列、服务定位器、状态、类型对象等。
- 概念片段：字节码、游戏循环、更新方法。这些示例主要用于展示代码结构，其中部分逻辑被有意禁用或尚未接入场景。
- 空间分区目前只有笔记，没有 Unity 示例场景。

## 笔记分类

- 重访设计模式：命令、享元、观察者、原型、单例、状态。
- 序列模式：双缓冲、游戏循环、更新方法。
- 行为模式：字节码、子类沙箱、类型对象。
- 解耦模式：组件、事件队列、服务定位器。
- 优化模式：数据局部性、脏标识、对象池、空间分区。
